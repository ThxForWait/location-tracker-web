# Albion Tracker Map

Сервер общей карты **Дорог Авалона** в Albion Online.

Дороги Авалона — сеть зон, связанных порталами, которые появляются и исчезают. Игроки с трекером ([location-tracker](https://github.com/ThxForWait/location-tracker)) присылают сюда свои переходы между зонами, а сервер проверяет их, объединяет отчёты разных игроков об одном портале и показывает живые порталы на карте.

## Возможности

- **API v1** на Django Ninja: приём переходов, вход трекера через браузер, документация `/api/v1/docs`;
- **вход на сайт через Discord**, у каждого устройства свой отзываемый токен;
- **защита от подделки данных:** лимиты запросов, проверка правдоподобия переходов, доверие к игрокам и подтверждение порталов несколькими независимыми игроками;
- **общая карта** живых порталов с таймерами; неподтверждённые рёбра рисуются пунктиром;
- **админка:** бан, доверенные игроки, отзыв токенов.

## Запуск

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

Скопируйте `.env.example` в `.env` и заполните его: ключ Django и ключи приложения Discord.

```bash
uv run python manage.py migrate
```

```bash
uv run python manage.py createcachetable
```

```bash
uv run python manage.py runserver 8000
```

Сайт открывать по http://127.0.0.1:8000, карта — `/map/`. Redirect приложения Discord: `http://127.0.0.1:8000/accounts/discord/login/callback/`.

Тесты: `uv run python manage.py test`
